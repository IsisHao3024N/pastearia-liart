# pastearia-liart

Liart - Landing Page da Pastelaria
Descrição
Landing page desenvolvida para a pastelaria Liart, com layout responsivo que se adapta a diferentes tamanhos de tela. O projeto utiliza HTML para a estrutura, CSS para o estilo visual, e media queries para garantir uma boa experiência em dispositivos móveis e desktops.

Funcionalidades
Layout limpo e atrativo

Menu de navegação fixo

Seção de apresentação dos pastéis

Informações de contato

Design responsivo via media queries

Tecnologias Utilizadas
HTML5

CSS3

Media Queries para responsividade
